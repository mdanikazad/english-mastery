# English Speaking Master

A prompt pack for turning ChatGPT into a brutally honest English speaking coach.
Goal: IELTS Speaking Band 9 fluency, interview-grade clarity, and confident
delivery in any environment.

## How to use

1. Open a new ChatGPT conversation.
2. Paste **00-system-setup.md** first. Send it. Wait for the confirmation.
3. Reply with one of the mode names in brackets, e.g.
   *"FLUENCY DRILL on the topic: tell me about a project you led."*
4. Speak (in voice mode) or type your answer.
5. Get ruthless feedback. Apply the rewrite. Repeat.
6. Use one mode per session. Switch modes across days.

Do not paste multiple mode prompts in one chat. They are designed to be
loaded one at a time on top of the system setup.

## Files

- `00-system-setup.md` — paste first, once per chat. Sets the rules and tone.
- `01-fluency-drill.md` — kills fillers, fast pace, long sentences, and
  broken formulation.
- `02-pronunciation.md` — IPA, mouth placement, connected speech.
- `03-interview-answer.md` — STAR/PAR structure, specifics, and the cure
  for "vague" feedback.
- `04-storytelling.md` — hook, stakes, detail, and 90-second scripts.
- `05-mock-interview.md` — full pressure simulation with running scores.
- `06-sentence-reform.md` — breaks long, tangled sentences into punchy units.
- `07-weekly-rotation.md` — the 7-day training schedule.

## The core rule

AI normally praises. This pack forbids it. The coach is required to start
every response with what you got WRONG or WEAK first. Praise, if any,
goes last and only if truly earned. If the answer is vague, the coach must
write the word `VAGUE` in caps and refuse to move on until you sharpen it.

## The four challenges this pack targets

- I can't speak in front of others (um, aa, broken sentences).
- I can't formulate sentences in my head.
- I speak too fast.
- I make sentences too long.

Each prompt attacks at least one of these directly. The weekly rotation
rotates between them so no single weakness hides.
